# Storyboard — 8 минут / 24 главы

01. 00:00–00:20 — Что сегодня строим: Codex + Claude Code + Hermes → Kie.ai → первое AI-video.
02. 00:20–00:40 — Карта системы: человек → агент → компьютер/VPS → MCP/API → Kie.ai → результат.
03. 00:40–01:00 — API, MCP, Skill: связь, инструменты, навык.
04. 01:00–01:20 — Pipeline vs Workflow: конвейер шагов против полного рабочего сценария.
05. 01:20–01:40 — Remote Desktop Commander как мост к Mac/Windows/VPS.
06. 01:40–02:00 — Агент один раз изучает окружение и сохраняет карту машины.
07. 02:00–02:20 — Research Once Protocol: исследовать → проверить → сохранить → переиспользовать.
08. 02:20–02:40 — Агент читает официальную документацию Kie.ai.
09. 02:40–03:00 — Безопасная передача API key, никаких секретов в чате.
10. 03:00–03:20 — Smoke test: auth, balance, дешёвая генерация.
11. 03:20–03:40 — Ищем готовый MCP/skill прежде чем писать свой.
12. 03:40–04:00 — Репозитории-кандидаты для аудита.
13. 04:00–04:20 — Один tool layer, три агента, три отдельных слоя памяти.
14. 04:20–04:40 — Декомпозиция AI-video вместо команды «сделай видео».
15. 04:40–05:00 — Reference + identity card персонажа.
16. 05:00–05:20 — Character consistency: исследовать причину drift и сохранить решение.
17. 05:20–05:40 — N=9: девять отдельных кадров одного персонажа и одной сцены.
18. 05:40–06:00 — Сценарий 10 секунд: 0–3 / 3–7 / 7–10.
19. 06:00–06:20 — Проверка актуальной видеомодели и точного model ID.
20. 06:20–06:40 — Research Once для MiniMax H3: model-specific prompting.
21. 06:40–07:00 — Сценарий → production prompt выбранной модели.
22. 07:00–07:20 — Upload refs → create task → Task ID → polling → result URL.
23. 07:20–07:40 — QA loop: identity, руки, речь, camera, continuity, соответствие сценарию.
24. 07:40–08:00 — Сохраняем весь production workflow как reusable skill.

## Definition of done

После урока ученик должен иметь:

- рабочий доступ агента к компьютеру или VPS;
- подключённый Kie.ai API без передачи ключа через чат;
- проверенный MCP/tool layer;
- зафиксированный Research Once Protocol;
- 9 reference images;
- сценарий;
- model-specific production prompt;
- первую завершённую video generation;
- QA результат;
- сохранённый reusable skill/workflow.
