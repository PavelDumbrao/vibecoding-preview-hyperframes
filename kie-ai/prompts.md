# Готовые промпты из урока

Используйте их последовательно. После каждого исследовательского этапа агент должен сохранить проверенное знание в свою постоянную project memory / skill.

## 1. Изучить рабочую машину

```text
Изучи мою рабочую машину и текущее окружение.
Проверь ОС, Git, Node.js, Python, Docker, основные проекты, рабочие директории и доступные AI/dev-инструменты.
Ничего не удаляй и не ломай.
После проверки создай краткую карту окружения и сохрани её в постоянную память проекта, чтобы в следующих задачах не исследовать машину заново.
```

## 2. Research Once Protocol

```text
Для этой новой темы сначала выполни Research Once.
1. Проверь официальную документацию и первоисточники.
2. Найди несколько сильных практических решений и репозиториев.
3. Сравни подходы.
4. Сделай минимальный реальный тест.
5. Зафиксируй, что фактически сработало.
6. Сохрани результат как reusable skill / project knowledge.
В будущем не исследуй тему заново без причины. Повторное исследование делай только если изменилась версия API/модели или обнаружена фактическая проблема.
```

## 3. Изучить Kie.ai

```text
Изучи актуальную официальную документацию Kie.ai: https://docs.kie.ai/
Не используй догадки по памяти.
Разберись с authentication, моделями, созданием задач, загрузкой файлов, Task ID, polling, result URL, ошибками и ограничениями API.
После исследования сделай краткую техническую карту интеграции и сохрани её в project knowledge.
```

## 4. Безопасно подключить API key

```text
Мне нужно подключить Kie.ai API key, но значение секрета нельзя отправлять в чат, URL/query string, argv или логи.
Используй безопасный одноразовый bridge или локальную форму.
После передачи проверь только факт успешной авторизации и доступность API. Никогда не печатай значение ключа.
```

## 5. Провести smoke test

```text
Проведи минимальный smoke test Kie.ai.
Проверь авторизацию, доступность аккаунта/баланса и выполни одну максимально дешёвую тестовую генерацию.
Если тест не проходит, диагностируй причину и не переходи к дорогой видеогенерации до исправления.
```

## 6. Найти готовый MCP/skill

```text
Не создавай интеграцию Kie.ai с нуля, пока не проверишь готовые решения.
Исследуй актуальные MCP, CLI и agent skills для Kie.ai.
Проверь свежесть, issues, зависимости, безопасность, поддерживаемые модели и совместимость с нашей архитектурой.
Начни аудит с https://github.com/felores/kie-cli-mcp и сравни с другими актуальными вариантами.
Пока ничего не устанавливай. Сначала покажи сравнение и обоснуй один выбранный вариант.
```

## 7. Подключить к конкретному агенту

```text
Подключи выбранный Kie.ai tool layer к этому агенту.
После установки сделай реальный тест вызова.
Зафиксируй точную конфигурацию, команды и найденные ограничения в постоянной памяти именно этого агента, чтобы Codex, Claude Code или Hermes не начинал настройку заново в следующей сессии.
```

## 8. Зафиксировать identity персонажа

```text
Изучи главный reference персонажа и создай Identity Card.
Зафиксируй признаки, которые нельзя менять: лицо, форму головы, волосы или их отсутствие, бороду, возраст, комплекцию, одежду и ключевые визуальные детали.
Эта Identity Card должна использоваться как контракт во всех последующих кадрах.
```

## 9. Research Once по character consistency

```text
Перед созданием серии кадров изучи актуальные лучшие практики character consistency для используемой image-модели.
Проверь официальные рекомендации и сильные практические примеры.
Сделай минимальный тест и сохрани рабочие правила в отдельный skill character-consistency.
Не делай случайные retry, если лицо начинает меняться. Сначала диагностируй причину.
```

## 10. Раскадровка N=9

```text
Создай storyboard N=9.
Мне нужны 9 ОТДЕЛЬНЫХ reference images, а не один коллаж.
Во всех девяти кадрах должен оставаться один и тот же персонаж по нашей Identity Card, одна визуальная сцена и единый стиль.
Меняться могут только ракурс, действие, поза и положение камеры.
После генерации проведи consistency QA по всем девяти кадрам.
```

## 11. Сценарий на 10 секунд

```text
На основе девяти кадров напиши подробный сценарий видео продолжительностью 10 секунд.
Разбей его на 0–3, 3–7 и 7–10 секунд.
Для каждого участка опиши действие персонажа, движение камеры, фон, эмоцию, реплику и переход к следующему действию.
Пока не превращай сценарий в prompt видеомодели.
```

## 12. Проверить видеомодель

```text
Проверь через актуальную документацию Kie.ai, доступна ли нужная видеомодель прямо сейчас.
Покажи точный model ID, поддерживаемую duration, resolution, reference mode и ограничения.
Не доверяй памяти и не выдумывай параметры.
```

## 13. Research Once для MiniMax H3

```text
Изучи, как правильно писать production prompts именно для MiniMax H3.
Мне не нужны общие советы по видеогенерации.
Проверь официальную документацию, reference image workflow, camera language, управление движением, речью, длительностью и допустимые параметры.
Дополнительно изучи сильные практические примеры creators.
Проверь выводы тестом и сохрани отдельный reusable skill minimax-h3-video.
```

## 14. Production prompt

```text
Теперь преврати утверждённый сценарий в production prompt для выбранной видеомодели.
Используй сохранённый model-specific skill.
Учитывай все 9 reference images, Identity Card, character consistency, движение камеры, continuity и русскую реплику.
Сначала покажи готовый prompt и кратко объясни его структуру. Генерацию пока не запускай.
```

## 15. Запустить генерацию

```text
Запускай генерацию через Kie.ai.
1. Подготовь и загрузи все reference images корректным способом.
2. Создай task.
3. Сохрани Task ID.
4. Делай polling с разумным интервалом и защитой от 429.
5. Получи result URL.
6. Скачай итоговый файл.
7. Проверь, что файл открывается и соответствует ожидаемому формату.
При ошибке сначала диагностируй причину, а не повторяй запрос вслепую.
```

## 16. QA Loop

```text
Проведи QA итогового видео.
Проверь identity персонажа, лицо, руки, речь/lipsync, физику движения, camera motion, continuity, фон и соответствие сценарию.
Если есть дефект, определи, на каком этапе workflow он появился. Верни проблему именно на этот этап, исправь правило и обнови соответствующий skill.
```

## 17. Сохранить весь workflow

```text
Зафиксируй весь проверенный процесс как reusable skill AI Video Production Pipeline.
Включи: reference → Identity Card → character consistency → N=9 storyboard → script → актуальная проверка модели → model-specific research → production prompt → upload refs → task → polling → result → QA loop.
Не сохраняй случайные детали одного ролика. Сохрани универсальные проверенные правила, чтобы следующее видео начиналось уже с готового workflow.
```
