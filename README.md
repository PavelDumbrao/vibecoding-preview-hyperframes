# Vibecoding Preview HyperFrames

Превью-видео для обучения по вайбкодингу, собранное как HTML-композиция в стиле HyperFrames.

## Что внутри
- `DESIGN.md` — визуальный стиль проекта
- `index.html` — короткая версия превью
- `index-3min.html` — расширенная 3-минутная версия
- `storyboard-3min.md` — структура и ритм длинной версии

## Идея ролика
Короткий промо-ролик про обучение, где вайбкодинг подаётся как способ быстро собирать AI-продукты: от brief и структуры до демо и ship-ready результата.

## Версии
1. `index.html` — короткий хук / promo preview
2. `index-3min.html` — 3-минутный explainer / course trailer

## Локальный просмотр
Открой нужный HTML-файл в браузере или запусти простой сервер:

```bash
python3 -m http.server 8017 --directory .
```

После этого можно открыть:
- `http://127.0.0.1:8017/index.html`
- `http://127.0.0.1:8017/index-3min.html`
